# Security Policy — AI SOS

The AI SOS maintainers take the security of this framework and host applications very seriously. If you discover a security vulnerability within AI SOS itself, we appreciate your help in disclosing it to us responsibly.

---

## Supported Versions

Only the latest stable release of AI SOS receives security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please DO NOT open a public GitHub issue for security vulnerabilities.**

Instead, please send a detailed security report to:

- **Security Team Email**: `security@ai-sos.org` (or create a [GitHub Private Vulnerability Report](https://github.com/your-org/AI-SOS/security/advisories/new))

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
1. **Description**: Clear description of the vulnerability.
2. **Impact**: Potential impact on host applications or data privacy.
3. **Reproduction**: Step-by-step instructions or PoC script.
4. **Environment**: Python version, framework versions (FastAPI/Flask/Django/OpenAI), and operating system.

---

## Disclosure & Response Policy

- **Initial Acknowledgement**: Within 24 hours of receiving your report.
- **Triage & Status Update**: Within 72 hours.
- **Fix & Advisory**: We aim to release a patch release within 7–14 business days depending on severity.
- **Credit**: Public credit will be awarded in the release notes and `CHANGELOG.md` upon resolution (unless anonymity is requested).
